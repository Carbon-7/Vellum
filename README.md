# Vellum

Vellum is a modern, AI-powered e-book reader and audiobook player built with Flutter. It combines a sleek, distraction-free reading experience with powerful features like text-to-speech, library management, and intelligent content interaction using Google Gemini.

## Features

- **📚 Smart Library**: Organize and manage your digital book collection efficiently.
- **📖 Advanced Reader**: High-quality PDF rendering with customizable reading modes.
- **🎧 Audiobooks & TTS**: Integrated text-to-speech engine and audio player for a seamless listening experience.
- **✨ AI-Powered**: Leverages Google Gemini for smart summaries and content interaction.
- **🎨 Modern Design**: Beautiful, responsive UI built with modern design principles, featuring dark mode and smooth animations.
- **⚡ Fast & Efficient**: Built on **Isar Database** for lightning-fast local data storage.

## Tech Stack

- **Framework**: Flutter
- **Language**: Dart
- **State Management**: Riverpod
- **Database**: Isar
- **AI**: Google Generative AI (Gemini)
- **Audio**: just_audio, audio_service, flutter_tts
- **UI**: Google Fonts, Lucide Icons

## Getting Started

### Prerequisites

- Flutter SDK (>=3.2.0)
- Dart SDK

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Carbon-7/Vellum.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Vellum
   ```
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Run the app:
   ```bash
   flutter run
   ```
